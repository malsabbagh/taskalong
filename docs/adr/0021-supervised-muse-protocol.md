# Supervised Muse protocol components and bounded trial intent

Status: proposed; offline runner development, no live admission.

Extend the separate supervised proposal seam with a pinned native startup plan,
strict preflight/session/turn bindings, untrusted event folding and one exact
priority-interrupt projection. Plans are data, not executable authority. Native
binary identity is measured without invoking it. Provider/model intent is fixed to
Muse/meta wonder-full High; no fallback, tool grant, trust or saved setting change.

Alternatives: accepting final stdout alone ignores turn terminal/cancellation and
reminder children. Reusing production admission would mix distinct authorities.
A separate original protocol reducer rejects unexpected grants, unavailable Mac
sandbox, absent model/High catalog selection, session/profile/turn drift, busy/queued
turns, truncated/cutoff or ambiguous output, unknown/foreign events, unexpected
server requests and child/tool/workflow/hook activity. These checks do not prove
such activity was prevented, authenticate imported frames or settle remote usage.

The initialize/initialized handshake and existing read-only profile match pinned
native observations. Only supported published fields are projected. The stable schema
provides model/list, usage/read, turn/interrupt and turn/completed. The experimental
export also exposes read-only account/read and settings/readSchema/settings/read.
Account projection names the credential lane, never returns a credential, and
does not bind the effective endpoint or enforce allowance. The isolated native
echo query returned loggedOut/credentialRequired=true. Settings schema exposes
web_fetch/web_search controls, but no reminder-roster suppression key in its served
key set. These supported read surfaces are projected as data; no login, logout or
settings write is added. Display identity values are omitted by the account reducer. Subscription
usage is last-observed, may be absent and is not an allowance/cost cap. An accepted
interrupt is not cancellation completion. Missing raw counters stay unknown;
provider raw token counters are retained verbatim, never summed into a made-up cap.
Foreground completion/final message alone is not turn completion. Turn completion
alone proves neither child lifetime nor remote settlement.

A model-free native echo canary created three reminder-child sessions despite
read-only, disable-write/shell, contributor-off and a plain text-only turn. Its
catalog was empty bundled metadata, usage/read absent, and its parent completed
without aggregate token counters. Its native journal also reported agent tools
including workflow, web_fetch, web_search, read_memory and cron despite zero client
capabilities. Client capability denial is distinct from agent-tool enforcement.
This is evidence of auxiliary activity in this
build, not a live provider success. No supported pre-dispatch reminder suppression
or aggregate inference cap has been established. Post-event interrupt cannot undo
already accepted remote work. Root exit preserves descendant uncertainty.

Offline replay accepts six explicitly supplied RPC responses plus notifications;
all saved requests are projections and none are sent. A bounded fold emits a local
response only after an unblocked complete turn/final answer, then existing patch
staging/manual review still applies. Inputs and report provenance remain unverified.
The run command stays unconditionally closed. No subprocess/network transport,
account bridge, credentials, grant or Store/schema mutation is added here.

A future live route still needs the existing-account/context binding and a qualified
bounded owner/transport. The owner must choose whether a supported no-child/cap
control is required or residual auxiliary/remote uncertainty is acceptable under
one explicit supervised invocation, local deadlines, retained exposure and no retry.
This ADR supplies no acceptance, vendor guarantee, executable permission or live
trial authority. The local limits in a plan are intended constraints, not a claim
that replay enforces wall time or whole-process cessation.


Later pinned help/echo observations provide a shorter exec candidate. Unlike serve,
exec supports empty preset, disable-reminders/web-tools, no-foreign-personal-context
and max-model-steps. Native echo with the compatible named read-only profile showed
empty tool/reminder rosters and one session. Legacy sandbox-network/approval-judge
flags conflict with that profile; parallel-tool flags are Meta-only. Rejected
argument combinations dispatched no prompt and remain preserved as negative data.
The source exposes this fixed candidate only as a data plan. Its canonical model
id must be explicitly supplied from the observed account catalog, never inferred
as a fallback from an alias. High is requested, not claimed observed.

The foreign-context exclusion still included the public user-skill canary in the
actual configured model context. Normal HOME projected accountLogin; fresh HOME
with existing native data/config roots remained loggedOut. No secret was copied.
No credential-preserving context isolation, native internal HTTP retry limit,
complete descendant lifetime or remote settlement is established. Empty tool/
reminder observations are actual Echo metadata, not proof of Meta execution or a
vendor hard cap. The live route stays closed pending the exact boundary decision.
