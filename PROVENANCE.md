# Provenance

This is an original TaskAlong implementation snapshot prepared for owner review.
No source implementation from earlier unrelated projects or vendor SDKs is
included. Interface research is documented where relevant; it is not a source
adaptation or license grant. Synthetic fixtures contain generated tasks and
deliberate redaction canaries, never real credentials or user projects.

The owner retains the development lineage, exact source manifest and audit
receipts privately. The public candidate excludes internal planning/handoff
documents, original Git history, discussions, raw logs and runtime state. The
per-file [ledger](docs/provenance.json) records candidate scope, not independent
proof of copyright ownership. The owner selected the [MIT License](LICENSE)
and supplied the copyright notice. Dependencies retain their own licenses;
the ledger records scope and attribution rather than independent rights clearance.
